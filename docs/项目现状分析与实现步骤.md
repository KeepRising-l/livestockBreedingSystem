```
1. 建包 app/modules/<模块>/，复制 health 模块 4 个文件：
   - model.py    继承 BasePO 建表（在 app/models/__init__.py 无需再 import，
                 modules 的模型由 api/v1/__init__.py 加载模块时连带注册进 Base.metadata）
   - schema.py   XxxIn / XxxUpdateIn / XxxOut / XxxQuery（入参/修改/返回/查询）
   - service.py  list_xxx / get_xxx / add_xxx / update_xxx / delete_xxx（多租户 farm_id 注入）
   - api.py      APIRouter，用 Depends(get_current_user) 取当前用户，_check_owner 做权限
   - __init__.py 统一出口：from <模块>.model import ...; from <模块>.api import router

2. 在 app/api/v1/__init__.py 加两行挂路由：
   from app.modules.<模块> import router as <模块>_router
   router.include_router(<模块>_router, prefix="/<模块>", tags=["<模块>模块"])

3. 跨模块引用统一用绝对路径：from app.modules.<其他模块>.model / .schema / .service import ...
   （例：health/service.py 引用档案 → from app.modules.animal.model import Animal）

4. 启动服务，浏览器打开 /docs，Swagger 里直接点 Try it out 测接口（不用等前端）

5. 前端 api/<模块>.ts 里封装对应请求方法（参考 health.ts 写法）

6. 前端 views/<模块>/ 下写页面：
   - 列表页：Element Plus ElTable + 分页 + 搜索栏
   - 新增/编辑：ElDialog 表单

7. router/index.ts 加路由 + Sidebar.vue 加菜单项
```
