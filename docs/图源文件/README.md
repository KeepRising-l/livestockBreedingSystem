# 大作业插图源文件

论文档（《软件工程B》大作业-智能养殖信息管理系统.docx）中全部插图的源文件，供自行修改后重新导出。

## 文件说明

| 文件 | 内容 |
| --- | --- |
| **大作业插图.drawio** | 推荐使用。8 个页面的 draw.io 可编辑源文件：总体用例图、场主端用例图、员工端用例图、ER-用户、ER-畜禽档案、ER-饲喂记录、ER-配种记录、系统整体ER图 |
| generate_drawio.py | 上面 .drawio 文件的生成脚本，想批量调整配色/布局可改这个脚本重新生成 |
| matplotlib脚本-修正版.py | 绘制全部 12 张 PNG 的 Python 脚本（最终版：含修正后的员工用例图、ER图、模块图、流程图） |
| matplotlib脚本-原始版.py | 最早一版脚本（仅留档，可忽略） |
| fig2_x / fig3_x / fig4_x *.png | 文档中实际嵌入的 12 张成品图 |

## 推荐修改方式（draw.io）

1. 打开 [https://app.diagrams.net](https://app.diagrams.net)（或安装 draw.io 桌面版 / VS Code 插件），打开 `大作业插图.drawio`；
2. 底部页签切换 8 个页面，拖拽图形、改文字、调颜色即可；
3. 改完后：**文件 → 导出为 → PNG**，缩放选 **200%**（插入 Word 更清晰）；
4. 回到 Word：右键对应图片 → **更改图片 → 来自文件**，选择导出的 PNG 替换，图注文字不用动。

> 时序图（图2.4、图2.5）、功能模块图（图3.1）、审核流程图（图4.1）目前只有 Python 脚本版源码；
> 如需 draw.io 版本，可以照 .drawio 内的图形样式手绘，或告诉我补上。

## matplotlib 方式（备选）

装好 Python + matplotlib（中文字体用微软雅黑）后：

```bash
cd docs/图源文件
python matplotlib脚本-修正版.py
```

会在脚本同目录生成/覆盖 figs/ 下的 PNG。图中所有坐标都是手写布局，
改文字请搜对应中文字符串，改位置就调坐标数字。
