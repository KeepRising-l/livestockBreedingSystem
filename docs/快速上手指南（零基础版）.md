# 智能养殖信息管理系统 · 快速上手指南

> 本文假设你**完全没用过本系统、甚至不熟悉网页系统**。
> 只讲最基础的内容：这是什么 → 怎么打开 → 怎么登录 → 每个按钮大概是干嘛的。
> 想深入了解具体业务操作，请阅读同目录下的《使用指南》。

---

## 一、这个系统是干嘛的？（一句话版本）

**它是养殖场的"电子账本"**：你家养了多少牛羊猪、关在哪个圈、今天喂了什么、打了什么针、配没配种、卖了多少钱——全部记在一个网页里，随时能查，不用翻纸质本子。

你只需要一个浏览器（Chrome / Edge 都行）就能使用，不用安装任何软件。

---

## 二、怎么打开这个系统？（3 步）

系统分两部分，都要开着才能用：

| 步骤 | 做什么 | 在哪做 |
| --- | --- | --- |
| ① | 启动**后端**（管数据的"大脑"） | 按《项目启动文档》第四章，在 `livestock_server` 目录运行 |
| ② | 启动**前端**（你看到的网页） | 按《项目启动文档》第五章，在 `livestock-web` 目录运行 `npm run dev` |
| ③ | **打开浏览器** | 地址栏输入 `http://localhost:5173` 回车 |

看到登录页面，就说明一切正常。

> 常见问题：打开网页一片空白？先确认第 ① ② 步的两个黑窗口（终端）都还在运行、没有报错红字。

## 三、怎么登录？

打开网页后你会看到一个登录框，填两样东西，点「登 录」：

- **账号**：一串英文字母，比如 `admin`
- **密码**：一串字符，比如 `admin123`

### 系统自带的账号（导入演示数据后可用）

| 账号 | 密码 | 是谁 | 你能干什么 |
| --- | --- | --- | --- |
| `admin` | `admin123` | 超级管理员 | 管账号、管权限，系统里最大的官 |
| `sunshine` | `123456` | 阳光牧场的**老板** | 看全场数据、批员工提交的记录、发工资 |
| `feeder01` | `123456` | 饲喂员（员工） | 只管喂料相关的事 |
| `vet01` | `123456` | 兽医（员工） | 只管打针看病相关的事 |
| `bajie` | `bajie123` | 八戒牧场的老板 | 只管八戒牧场（猪场） |

> **新手建议先用 `admin` / `admin123` 登录**，能看到所有功能，方便熟悉系统。
> 没有账号怎么办？员工账号不能自己注册，要由**老板**在「员工管理」页面里创建。

## 四、登录后第一眼看到什么？

登录成功后进入**数据大屏**（首页），一屏看到整个场的概况：

- **几个数字卡片**：现在存栏多少头、圈舍多少个、有几条记录等你审批
- **几张图表**：圈舍分布、畜种分布等
- **左侧一列菜单**：系统的全部功能都在这里，点一下进一个页面

**不用怕点多**：所有菜单点进去都是"看 + 填表"，不会把系统弄坏。

## 五、左侧菜单都是干嘛的？（大白话版）

从上到下依次解释，每条一句话：

| 菜单 | 大白话解释 |
| --- | --- |
| 📊 数据大屏 | 首页总览，看大数字和图表 |
| 🏢 养殖场管理 | 改养殖场名字地址、给员工开账号、配置工资 |
| 🐄 我的养殖场 | 核心业务都在这下面（见下方"六个日常"） |
| ⚙️ 系统管理 | 管用户、权限、字典——普通养户用不到，跳过 |

点开「我的养殖场」→ 选一个畜种（牛场/羊场/猪场），里面的菜单是：

| 菜单 | 大白话解释 |
| --- | --- |
| 圈舍管理 | 场的"房间表"：有哪些圈、每圈关了几头 |
| 档案管理 | 每头牲畜的"户口本"：入栏登记、耳标、品种、生日 |
| 饲喂管理 | 今天喂了什么、喂多少；可先定"饲喂方案"再照着喂 |
| 物资库存 | 饲料、药品的库存；进货、领用都在这里记 |
| 防疫诊疗 | 打疫苗（防疫记录）、看病（诊疗记录） |
| 繁育管理 | 配种、产仔、怀孕预警 |
| 审核中心 | 员工提交的记录，老板在这里批"通过/驳回" |
| 销售财务 | 卖牲畜（销售订单）、记开销（成本）、算利润 |
| 统计分析 | 各种汇总图表，看经营情况 |

## 六、一个养殖场日常怎么用？（6 步走完一遍）

按这个顺序操作一遍，就理解整个系统了：

1. **先建圈舍**：圈舍管理 → 点「新增」→ 填圈舍编号和类型 → 保存。
2. **牲畜进场登记**：档案管理 → 个体入栏 → 填品种、性别、入栏日期 → 保存。系统会自动给它生成一个**耳标**（就是牲畜的"身份证号"）。
3. **每天喂食记录**：饲喂管理 → 饲喂记录 → 选圈舍和方案 → 填数量 → 保存。
4. **饲料不够了进货**：物资库存 → 进货记录 → 填饲料名称、数量、价格。
5. **配种与产仔**：繁育管理 → 配种记录；快到预产期时「繁育预警」会自动提醒。
6. **卖出去收钱**：销售财务 → 销售订单 → 选耳标 → 填售价 → 系统自动算这头赚了多少。

> 员工提交的记录需要**老板在审核中心点"通过"**后才正式生效。

## 七、几个必须懂的名词（黑话翻译）

| 名词 | 意思 |
| --- | --- |
| 耳标 | 挂在牲畜耳朵上的编号牌，相当于它的身份证号，全系统靠它找这头牲畜 |
| 入栏 / 出栏 | 进养殖场 / 离开养殖场（卖掉、宰杀都算出栏） |
| 存栏 | 现在场里还有多少头 |
| 圈舍 | 关牲畜的房间/棚子 |
| 畜种 | 牛、羊、猪这类的大分类 |
| 审核 | 员工填的记录要老板点"通过"才算数 |

## 八、常见问题（新手最常问）

**Q：点了登录没反应 / 提示错误？**
A：检查账号密码是否输错（区分大小写）；再确认后端服务在运行。

**Q：我看不到某个菜单？**
A：是权限问题——员工账号只能看到自己岗位的菜单。用 `admin` 登录能看到全部。

**Q：我的养殖场下面是空的？**
A：还没导入演示数据，或该账号名下还没有养殖场。按《项目启动文档》4.4 节跑一遍数据脚本即可。

**Q：页面点了没反应、内容不变？**
A：按 `F5` 刷新一次；还不行就关掉浏览器重开，并确认后端终端没有红色报错。

**Q：可以多人同时用吗？**
A：可以。后端开着，局域网内其他电脑也能访问（需按启动文档做局域网配置）。
