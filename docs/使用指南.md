# 智能养殖信息管理系统 · 新手使用指南

> 面向完全没有用过本系统的新手。跟着这份指南，就能学会：登录 → 分清身份 → 完成日常养殖业务 → 看懂报表。
> 当前版本：v1.29（同步项目 v1.29：新增批量入栏 Excel 导入、数据大屏导出 Excel；原"待开发"的母畜生理状态/首页今日待办/品种字典对齐三项已全部完成）

---

## 一、这个系统是干嘛的？

就是给你管养殖场用的"数字账本"——牛羊猪的 **档案、圈舍、喂料、配种、打针、饲料库存、卖钱、算利润**，全在一个网页里管理，不用再翻纸质本子。

> 记住一句话：**谁养了什么、养在哪、喂了什么、生了没、卖了多少钱，都在这里查得到。**

---

## 二、怎么登录？

1. 打开网址（本机运行一般是 `http://localhost:5175`）
2. 输入 **账号 + 密码**
3. 点「登 录」

系统里一共有 **三种身份**：

| 身份 | 测试账号 | 密码 | 适合谁 |
|---|---|---|---|
| 养殖场主（老板） | `sunshine` | `123456` | 全场数据都看得到、能审批、能发工资 |
| 员工（饲喂员等） | `feeder01` | `123456` | 只管自己岗位的活 |
| 超级管理员 | `admin` | `admin123` | 系统维护，管账号/字典/权限 |

> 没有账号？目前员工账号由**养殖场主在「员工管理」里创建**，不开放员工自己注册。

---

## 三、三种身份分别能干嘛？

### 🐮 养殖场主（老板）

登录后进 **数据大屏**，一屏看到全场概况：
- 今日存栏、本月入栏/出栏、累计销售额、累计利润
- 圈舍分布、畜种分布、生长阶段分布
- 待审核记录数、待处理预警数

左侧菜单从上到下是全部功能：**圈舍 → 档案 → 饲喂 → 繁育 → 防疫 → 物资 → 销售财务 → 统计 → 审核**。老板**什么都能看、什么都能批**。

「养殖场管理」菜单里还有：养殖场信息、员工管理（给员工开账号）、薪资配置。

### 👨🌾 员工（按岗位）

登录后直接进 **自己的工作台**，只显示自己岗位要干的活：
- **饲喂员**：今天要喂哪些圈舍、登记饲喂记录、查看饲喂方案
- **兽医**：防疫记录、诊疗记录，打针和看病登记
- **繁育员**：配种记录、繁育预警（该孕检了、快产了）
- **库管员**：库存不足提醒、领用登记、进货登记

员工提交的记录，要等老板在审核中心审批通过后才正式生效。

### ⚙️ 超级管理员

管系统本身：用户、角色权限、菜单、字典、日志、通知公告。**普通养殖场用不上，一般不用碰。**

## 四、多畜种怎么切？

同时养了牛、羊、猪的话，左侧「我的养殖场」下会有 **牛场 / 羊场 / 猪场** 三个目录：
- 点「牛场」看牛的数据，点「羊场」自动切到羊，互不干扰
- **只开一个畜种场，打开别的场会自动收起上一个**（手风琴，不会越开越长）
- 注册养殖场时选了几种畜，这里就显示几个场；只选一种就只显示一个场

## 五、日常业务怎么走？（最常用的 6 步）

1. **建圈舍**：圈舍管理 → 新增。类型：A=保育舍、B=育成舍、C=繁育舍、D=种用
2. **进新牲畜**：档案管理 → **个体入栏**（单只）或 **批量入栏**（一批），系统自动分配圈舍、自动生成耳标。**批量入栏还支持「从 Excel 导入」**：点右上角「从 Excel 导入」→ 下载模板 → 按模板填好每头（品种 / 性别 / 出生日期 / 入栏日期 / 来源 / 备注）→ 上传预览 → 确认导入；有问题的行会自动跳过，结果里会标出失败原因，不影响其它行
3. **天天喂**：饲喂管理 → 饲喂记录，选圈舍、选方案、记数量（饲喂员的工作台直接有入口）
4. **配种繁殖**：繁育管理 → 配种记录 → 配种成功后自动算预产期，快产了有「繁育预警」提醒
5. **打针看病**：防疫诊疗 → 防疫记录（打疫苗）/ 诊疗记录（看病）
6. **卖钱出栏**：销售财务 → 销售订单 → 选耳标自动算出栏天数 → 自动统计销售额和利润

> 全程有耳标（每只牲畜唯一的身份编号），所有记录都挂在耳标上，想查哪只查哪只。

## 六、实用小贴士

- **个人中心**：右上角头像 → 个人中心，查看自己账号的角色和权限
- **统计报表**：统计分析有 5 个页面（综合 / 存栏繁育 / 防疫诊疗 / 物资消耗 / 财务），全自动生成，不用手动算
- **数据大屏导出**：数据大屏右上角「导出 Excel」一键把全场报表（KPI / 今日待办 / 入栏出栏趋势 / 畜种分布 / 生长阶段 / 圈舍存栏）下载成 Excel 文件
- **库存提醒**：库管员工作台能看到库存不足的物资，及时补货
- **忘记密码**：找超管（admin）在 系统管理-用户 里重置
- **数据安全**：系统有登录日志，谁什么时候登录都记着

## 七、如何添加新的品种（牛/羊/猪）

> 想养一个系统里还没有的品种（比如"娟姗牛"）？**不用改代码、不用找开发**，直接在字典里加一条即可。

**品种是怎么存的**：所有品种存在「品种字典」里，每条记录带它属于哪个畜种（牛/羊/猪）。前端选品种的下拉框是**自动读取字典**的——字典里加了，下拉框就出现，系统一行代码都不用改。

**添加步骤（需超级管理员 admin 登录）**：
1. 用 `admin / admin123` 登录
2. 左侧「系统管理」→「字典管理」
3. 找到 `sys_breed`（品种字典）
4. 点「添加」一条，填：
   - **字典标签**：品种名（如：娟姗牛）
   - **字典键值**：和标签一样写品种名
   - **扩展信息**：填 `{"species":"cattle"}`（牛填 cattle，羊填 sheep，猪填 pig）
   - **状态**：正常
5. 保存后，回到档案 / 入栏页面刷新，品种下拉里就能选到新品种了

**批量导入很多品种**：写个脚本向字典表插入多条带 `{"species":"..."}` 的记录即可，几秒完成。

> ⚠️ 说明：新品种目前只作为「档案标签」。系统按**畜种**（牛/羊/猪）计算生长周期、圈舍分配和饲喂，不按品种区分。

> 目前功能设计文档里的功能已**全部实现**：母畜生理状态（发情/妊娠/泌乳/休情/淘汰）、首页今日待办（临产/库存不足提醒）、品种字典对齐等均已完成，日常养殖流程都能走通。

## 八、常见问题（FAQ）

**Q：登录后什么都没有 / 一片空白？**
A：确认账号密码正确，且用的浏览器能访问到后端（后端服务要开着）。

**Q：员工登录后很多菜单看不到，正常吗？**
A：正常。员工按岗位只能看到自己岗位的菜单和操作，这是权限控制，不是坏了。

**Q：审核是什么？为什么要审批？**
A：员工提交的饲喂/防疫/库存等记录，需要老板确认无误后通过，避免乱记错记。老板在「审核中心」处理。

**Q：我点「牛场」怎么没有？**
A：说明你的养殖场注册时没选"牛"这个养殖种类，只有注册时选的畜种才会显示。
