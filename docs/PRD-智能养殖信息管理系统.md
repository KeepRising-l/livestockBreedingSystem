## 2. 产品概述

### 2.1 产品定位

智能养殖信息管理系统是一款面向中大型畜禽养殖场（牛 / 羊 / 猪）的 SaaS 化全流程信息化管理平台。系统以"圈舍—个体档案—饲喂—繁育—防疫—物资—销售—财务"为主线，将养殖场的日常生产、物资消耗、销售结算与数据决策进行端到端数字化，帮助养殖场主与员工摆脱纸质台账与 Excel，实现数据可追溯、成本可核算、决策可量化。

系统采用 IP 访问 + 浏览器端渲染模式，支持 PC 端与手机浏览器访问，适配中小型养殖场轻量化部署诉求。

### 2.2 产品目标

| 目标层级 | 目标描述 | 衡量指标 |
| --- | --- | --- |
| 业务目标 | 实现养殖场全流程无纸化、数据在线化 | 纸质台账替换率 ≥ 95% |
| 管理目标 | 单只畜禽从入栏到出栏的全生命周期成本可追溯 | 单只利润核算覆盖率 100% |
| 效率目标 | 饲喂、繁育、防疫任务自动提醒与排程 | 关键节点漏操作率 ≤ 2% |
| 决策目标 | 数据大屏实时呈现存栏、繁育、防疫、物资、财务状况 | 大屏数据延迟 ≤ 5 分钟 |
| 扩展目标 | 支持牛 / 羊 / 猪三类养殖场独立运行、可扩展更多畜种 | 新增畜种周期 ≤ 2 周 |

### 2.3 产品价值

- **对养殖场主**：实时掌握存栏、成本、利润；自动预警临产、孕检、库存不足；可自定义员工薪资与饲喂方案。
- **对一线员工**：明确每日饲喂、防疫、繁育任务清单；扫码 / 选耳标快速录入；减少漏投喂、漏防疫。
- **对数据决策**：单只利润核算 + 物资消耗闭环；财务成本自动归集，告别手工算账。
- **对系统扩展**：模块化结构，模块可增加；三类养殖场各自独立，互不干扰。

## 3. 用户角色与权限

### 3.1 角色定义

系统设置三类操作角色：

| 角色 | 角色编码 | 说明 |
| --- | --- | --- |
| 顶层超级管理员 | `SUPER_ADMIN` | 平台运营方，管理所有养殖场主账号、系统配置、数据总览 |
| 养殖场主管理员 | `FARM_OWNER` | 养殖场老板账号，注册时创建，拥有该养殖场全部数据权限与员工管理权限 |
| 养殖场员工 | `FARM_STAFF` | 在职员工，按岗位细分为饲喂员 / 繁育员 / 兽医 / 库管员 |

员工岗位细分：

| 岗位 | 岗位编码 | 主要职责 |
| --- | --- | --- |
| 饲喂员 | `FEEDER` | 饲喂方案执行、饲喂记录录入、饲喂状态更新 |
| 繁育员 | `BREEDER` | 配种记录、产犊/产羔/产仔记录、繁育预警处理 |
| 兽医 | `VET` | 防疫接种、诊疗记录、兽药领用 |
| 库管员 | `KEEPER` | 物资进销存、领用审核、库存预警 |

## 4. 名词术语表

| 术语 | 定义 |
| --- | --- |
| 耳标 | 畜禽个体唯一标识，4 位数字。前两位为圈舍简码，后两位为该圈舍内顺序号；删除或出栏后空出的耳标可继续使用 |
| 圈舍 | 饲养畜禽的物理单元，分为 A 育雏舍 / B 育成舍 / C 繁育舍 / D 种畜圈舍四类 |
| 圈舍简码 | 圈舍编号的两位简码，用于拼接耳标前两位 |
| 容纳上限 | 单个圈舍可容纳的畜禽数量上限：育雏舍 12、育成舍 12、繁育舍 6、种畜圈舍 1 |
| 当前存栏数 | 圈舍内处于"在栏"状态的畜禽数量 |
| 生长阶段 | 按日龄划分的生理阶段（犊牛/保育期/生长期/育肥期等），不同畜种日龄区间不同 |
| 日龄 | 畜禽从出生日期到当前日期的天数 |
| 在栏 | 畜禽处于正常饲养状态 |
| 种用 | 畜禽被选为种畜，处于种畜圈舍 |
| 隔离 | 畜禽因健康原因被隔离观察 |
| 待出栏 | 畜禽达到出栏标准，等待销售 |
| 已出栏 | 畜禽已完成销售出栏 |
| 自繁 | 畜禽由本场繁育出生 |
| 外购 | 畜禽从外部购入 |
| 全价颗粒料 | 猪场使用的全价配合饲料，无需额外搭配精料/青贮/干草 |
| 妊娠期 | 母畜配种后到分娩的时段，牛 0-280 天、羊 0-150 天、猪 0-114 天 |
| 孕检 | 配种后一定天数的妊娠确认检查（牛 60 天） |

## 6. 详细功能需求

### 6.1 登录注册模块

#### FR-001 IP 访问与登录入口

| 项 | 内容 |
| --- | --- |
| 功能描述 | 用户在 PC 或手机浏览器输入部署 IP，进入系统登录界面；已有账号输入账号密码登录，无账号进入注册流程 |
| 输入 | 部署服务器 IP、账号、密码 |
| 处理逻辑 | 1. 浏览器访问 `http://<IP>`；2. 后端校验 IP 合法性并返回登录页；3. 输入账号密码后调用 `auth/login`；4. 校验通过生成 Token，按角色路由到对应首页 |
| 输出 | 登录成功跳转首页；失败返回错误提示 |
| UI 要点 | 登录页包含账号、密码输入框、"登录"按钮、"没有账号？立即注册"链接 |
| 业务规则 | BR-001：账号唯一，手机号作为账号主体 |
| 异常处理 | 账号不存在 / 密码错误 / 账号被禁用，分别返回对应错误码 |

#### FR-002 注册类型选择

| 项 | 内容 |
| --- | --- |
| 功能描述 | 新用户注册时选择账号类型：养殖场主管理员（老板账号）/ 养殖场员工 |
| 输入 | 账号类型单选 |
| 处理逻辑 | 选择不同类型后展示对应的注册表单字段 |
| 输出 | 进入对应类型的注册表单 |
| 业务规则 | BR-002：账号类型一经注册不可更改；员工注册时所在养殖场必须已存在 |

#### FR-003 养殖场主管理员注册

| 项 | 内容 |
| --- | --- |
| 功能描述 | 老板账号注册，创建养殖场并成为该养殖场主管理员 |
| 输入 | 养殖场名称、姓名、手机号、养殖牲畜种类（牛/羊/猪，可多选）、登录密码 |
| 处理逻辑 | 1. 校验手机号未注册；2. 创建养殖场主记录；3. 按所选畜种创建对应养殖场实例（牛场/羊场/猪场相互独立）；4. 初始化默认圈舍、饲喂方案、薪资标准 |
| 输出 | 注册成功，跳转登录 |
| 业务规则 | BR-003：单选养殖则首页左侧导航"我的养殖场"仅显示对应场；多选则显示多个子项 |
| 异常处理 | 养殖场名称重复、手机号已注册时阻断并提示 |

#### FR-004 养殖场员工注册

| 项 | 内容 |
| --- | --- |
| 功能描述 | 员工账号注册，绑定所在养殖场与岗位 |
| 输入 | 养殖场名称（下拉选择）、姓名、手机号、就职岗位（饲喂员/兽医/繁育员/库管员）、登录密码 |
| 处理逻辑 | 1. 校验所选养殖场存在；2. 创建员工记录并关联养殖场；3. 按岗位分配权限 |
| 输出 | 注册成功，跳转登录 |
| 业务规则 | BR-004：员工注册后默认状态为"待养殖场主审核"，审核通过后方可登录使用 |
| 异常处理 | 养殖场不存在、手机号已注册、岗位未选择时阻断 |

#### FR-005 多养殖场导航

| 项 | 内容 |
| --- | --- |
| 功能描述 | 养殖场主注册时多选畜种，首页左侧"我的养殖场"显示多个子项，可切换查看 |
| 输入 | 点击"我的羊场""我的牛场""我的猪场"切换 |
| 处理逻辑 | 切换后加载对应养殖场的圈舍、档案、饲喂等数据 |
| 业务规则 | BR-005：三类养殖场系统各自独立，数据不互通 |

### 6.2 首页（待办、提醒、统计概览）

#### FR-006 首页数据概览

| 项 | 内容 |
| --- | --- |
| 功能描述 | 登录后首页展示当前养殖场的核心运营指标与待办提醒 |
| 输入 | 当前登录用户的养殖场 ID 与角色 |
| 处理逻辑 | 聚合存栏数、待出栏数、今日待饲喂任务、临产预警、库存预警、待审核单据数 |
| 输出 | 卡片式数据概览 + 待办列表 |
| UI 要点 | 顶部 4 个数据卡片（总存栏 / 待出栏 / 今日待饲喂 / 库存预警）；中部今日代办列表；底部近 7 天存栏趋势小图 |

#### FR-007 今日代办

| 项 | 内容 |
| --- | --- |
| 功能描述 | 展示当前用户今日需处理的任务，包括临产提醒、孕检提醒、未发情提醒、库存不足提醒、待审核单据 |
| 输入 | 用户角色与岗位 |
| 处理逻辑 | 按岗位过滤：繁育员看繁育类预警；库管员看库存预警；养殖场主看全部 + 待审核 |

## 8. 业务流程图

### 8.1 入栏流程

```
开始
  │
  ├─ 选择入栏方式（个体 / 批量）
  │
  ├─ 录入品种、性别、来源、出生日期、入栏日期
  │
  ├─ 系统按生长阶段匹配圈舍类型
  │
  ├─ 查找未满圈舍 → 自动分配 / 提示新建
  │
  ├─ 按耳标规则生成耳标（复用空出耳标）
  │
  ├─ 写入档案记录 + 圈舍存栏数 +1
  │
  └─ 结束
```

### 8.2 饲喂流程

```
开始
  │
  ├─ 系统按圈舍 × 饲喂方案生成当日饲喂计划（早 / 晚）
  │
  ├─ 饲喂员选择圈舍与时段
  │
  ├─ 录入实际投喂重量
  │
  ├─ 状态变更为"已投喂"
  │
  ├─ 扣减饲料库存
  │
  ├─ 累计饲料成本到档案
  │
  └─ 结束
```

### 8.3 出栏销售流程

```
开始
  │
  ├─ 档案状态改为"待出栏"（育肥期满，养殖场主操作）
  │
  ├─ 选择待出栏耳标（可批量）
  │
  ├─ 系统自动读取饲养天数、物资消耗总成本
  │
  ├─ 录入客户、单价、销售日期
  │
  ├─ 提交销售单 → 进入待审核
  │
  ├─ 养殖场主审核通过
  │
  ├─ 档案状态改为"已出栏"，填写出栏日期
  │
  ├─ 生成销售订单 + 利润核算
  │
  └─ 结束
```

### 8.4 配种产仔流程

```
开始
  │
  ├─ 母畜达到可繁育日龄（牛365 / 羊300 / 猪220）
  │
  ├─ 繁育员登记配种记录
  │
  ├─ 系统计算预计生产日期 = 配种日期 + 妊娠期
  │
  ├─ 配种后 60 天（牛）孕检提醒
  │
  ├─ 状态改为"已确认妊娠"
  │
  ├─ 临产 15 天每天提醒
  │
  ├─ 分娩 → 登记产仔记录（数量 / 成活 / 死亡）
  │
  ├─ 成活仔畜批量入栏档案
  │
  ├─ 产后 60 天未发情提醒
  │
  └─ 结束
```

### 8.5 审核流程

```
员工提交单据
  │
  ├─ 进入待审核列表
  │
  ├─ 养殖场主审核
  │     ├─ 通过 → 单据生效 → 推送结果通知
  │     └─ 驳回 → 填写驳回原因 → 推送结果通知 → 员工修改重新提交
  │
  └─ 结束
```
