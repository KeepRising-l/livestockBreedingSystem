项目简介

智能养殖信息管理系统是一套为中小型养殖场（牛 / 羊 / 猪）设计的全栈业务管理系统。系统覆盖畜禽全生命周期管理，从个体/批量入栏、耳标自动生成与圈舍自动分配，到饲喂、防疫诊疗、繁育、物资库存的日常记录与审核，再到销售结算、成本核算、薪资发放和财务利润分析，并以统计大屏直观呈现经营状况。

系统同时内置了每日自动执行的定时任务（生长阶段刷新、繁育预警、库存过期、历史清理）与基于岗位的 RBAC 权限体系，兼顾自动化与精细化管控。

核心功能

按业务模块划分，覆盖养殖场经营全流程

档

畜禽档案与圈舍

牛/羊/猪个体与批量入栏，耳标自动生成，圈舍容量与自动分配，档案历史与恢复。

喂

饲喂管理

按畜种/阶段/圈舍配置饲喂方案，饲喂记录提交与场主审核，饲喂成本自动核算。

医

防疫诊疗

防疫记录（支持批量）与诊疗记录，疫苗白名单校验，提交后待审核流转。

育

繁育管理

母畜/公畜档案、配种记录（自动算预产期）、孕检登记、产犊记录、繁育预警。

库

物资库存

饲料/疫苗/兽药库存，进货与领用记录审核流转，库存状态与临期自动维护。

审

审核中心

饲喂/进货/领用/防疫/诊疗五类记录统一待审聚合，场主一键通过/驳回。

财

销售财务

出栏销售与结算，出栏成本分摊算法（饲喂/人工/药品），利润核算与薪资发放。

统

统计分析

综合大屏与存栏繁育、防疫诊疗、物资消耗、财务四维统计，ECharts 可视化。

权

系统管理与权限

用户/角色/菜单/日志/通知/字典管理，RBAC 岗位权限（饲喂员/兽医/繁育员/库管员）。

亮点特性

算法与工程细节

耳标自动生成：圈舍号 + 顺序号，空号自动复用，跨圈舍变更联动重算。
圈舍自动分配：按容量与空位智能分配入栏圈舍。
生长阶段判定：牛/羊/猪三套阶段配置，按日龄自动计算。
出栏成本分摊：饲喂成本按记录累加、人工按薪资分摊、药品成本核算，利润自动计算。
自动预警：孕检 60 天、临产 15 天、产后未发情 60 天提醒，每日定时扫描去重生成。
定时任务：APScheduler 每日刷新生长阶段、库存状态，并清理半年以上历史。
RBAC 权限：员工按岗位看到对应菜单、调用对应接口，超管/场主全量。
数据大屏：今日存栏、入栏出栏、销售利润 KPI 与趋势图一屏掌握。

技术架构

后端（livestock_server）

  • FastAPI + SQLAlchemy 2.0 + PyMySQL，模块化分层（model / schema / service / api）
  • JWT 认证 + bcrypt 密码哈希，统一响应与业务异常体系
  • APScheduler 定时任务，登录/操作日志自动留痕

前端（livestock-web）

  • Vue 3 + Vite + TypeScript + Element Plus + Pinia
  • vue-echarts 统计图表，axios 统一请求封装与路由守卫

数据与运维

  • MySQL 数据库，20+ 张业务表（档案/圈舍/饲喂/防疫/繁育/库存/财务/系统/RBAC）
  • 字典数据预置初始化，支持 Docker 化部署（规划中）
